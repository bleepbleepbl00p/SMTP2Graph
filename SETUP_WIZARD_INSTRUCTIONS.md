# SMTP2Graph Setup Wizard — Build Instructions for Claude Sonnet 4.6

## Goal

Make the container start **without** a pre-existing `config.yml`. When no config exists (or the config is missing required fields like tenant/appReg), the application enters **Setup Mode** — only the WebUI starts, presenting a setup wizard that guides the user through initial configuration. Once the config is saved, the SMTP relay starts automatically.

## Current Architecture (read these files first)

```
src/server.ts                      # Entry point — loads config, starts SMTP, optionally starts WebUI
src/classes/Config.ts              # Static config loader/validator
src/classes/SMTPServer.ts          # SMTP relay server
src/classes/MailQueue.ts           # Mail queue manager
src/webui/WebServer.ts             # Express server (requires MailQueue + SMTPServer refs)
src/webui/routes/configRoutes.ts   # Config API endpoints
src/webui/routes/healthRoutes.ts   # Health/queue/logs endpoints
src/webui/routes/accountRoutes.ts  # Account CRUD endpoints
src/webui/services/ConfigService.ts # Config read/write/validate service
src/webui/public/index.html        # Frontend UI
src/webui/public/app.js            # Frontend logic
src/webui/public/style.css         # Retro theme styles
docker/startup.sh                  # Container entrypoint
config.example.yml                 # Example config
```

## Important Constraints

- **Never push to upstream** — only push to `fork` remote (bleepbleepbl00p's fork)
- **Preserve the retro Windows 98 theme** in all new UI elements
- **WebUI must remain optional** when running outside Docker with a complete config
- **The SMTP relay must continue to work exactly as before** when a valid config exists
- **Do not break existing API endpoints** — add new ones as needed
- **Keep changes minimal** — don't refactor code that doesn't need to change

## Implementation Steps

### Step 1: Modify `docker/startup.sh`

**Current behavior:** Exits with error if `config.yml` doesn't exist.

**New behavior:** If `config.yml` doesn't exist, create a minimal bootstrap config that enables only the WebUI in setup mode, then start the server.

```bash
#!/bin/sh

WORKDIR=`pwd`
CFGFILE="$WORKDIR/config.yml"

if [ ! -f "$CFGFILE" ]; then
    echo "No config.yml found — starting in Setup Mode (WebUI only)..."
    cat > "$CFGFILE" << 'YAML'
# SMTP2Graph — Generated by Setup Wizard
# Complete the setup via the WebUI at http://<host>:3000

mode: full

webui:
  enabled: true
  port: 3000
  listenAddress: 0.0.0.0
  username: admin
  password: changeme
YAML
fi

# Run SMTP2Graph
exec node /usr/local/bin/smtp2graph.js --receive.port=587
```

### Step 2: Add Setup Mode to `src/classes/Config.ts`

Add a static getter that determines whether the config is "complete" (has minimum required fields to run the SMTP relay):

```typescript
/**
 * Returns true if the config is missing required send/accounts configuration.
 * In setup mode, only the WebUI should start.
 */
static get setupMode(): boolean {
    const data = this.#configData;
    if (!data) return true;

    // Has multi-account config?
    if (data.accounts && Array.isArray(data.accounts) && data.accounts.length > 0) {
        return false;
    }

    // Has single-account send config?
    if (data.send?.appReg?.tenant && data.send?.appReg?.id) {
        return false;
    }

    // Mode is 'receive' only — no send config needed
    if (data.mode === 'receive') {
        return false;
    }

    return true;
}
```

**Also modify `Config.validate()`** so it does NOT throw/exit when in setup mode. Currently it fails fast on missing `send.appReg` fields. Change the validation to:
- Still validate structural correctness (types, IP formats, etc.)
- Skip the "required send config" validation when `setupMode` is true
- The WebUI section should validate independently (it has its own required fields)

Look at how `validate()` currently works and make the minimal change. The key insight: if `webui.enabled` is true but `send.appReg` is incomplete, that should be allowed in setup mode.

### Step 3: Modify `src/server.ts` Entry Point

**Current flow:**
1. Validate config (exits on failure)
2. Create MailQueue
3. Create SMTPServer and listen
4. If webui enabled, create WebServer and listen

**New flow:**
1. Load config (don't validate send requirements yet)
2. Check `Config.setupMode`
3. **If setup mode:**
   - Log a clear message: "Setup Mode — no send configuration found. Access the WebUI to complete setup."
   - Force-enable the WebUI if not already enabled
   - Start ONLY the WebServer (pass `null` for queue and smtpServer)
   - Do NOT start MailQueue or SMTPServer
4. **If normal mode:**
   - Validate fully (existing behavior)
   - Start MailQueue, SMTPServer, and optionally WebServer (existing behavior)

```typescript
// Pseudocode for the new flow in server.ts
const config = Config.validate(); // modified to allow setup mode

if (Config.setupMode) {
    log.info('Setup Mode — no send configuration found.');
    log.info(`Complete setup via WebUI at http://${Config.webuiListenAddress}:${Config.webuiPort}`);

    const { default: WebServer } = await import('./webui/WebServer');
    const webServer = new WebServer(null, null); // null queue and smtp
    await webServer.listen();

    log.info('Waiting for configuration to be completed via WebUI...');
} else {
    // existing normal startup code unchanged
}
```

### Step 4: Modify `src/webui/WebServer.ts`

**Changes needed:**
- Accept `null` for `queue` and `smtpServer` constructor params
- Add a `setupMode` flag based on whether these are null
- When in setup mode, only mount config routes and a setup-specific health endpoint
- Add a new route: `GET /api/setup-status` that returns `{ setupMode: true/false }`
- Add a new route: `POST /api/setup/complete` that:
  1. Validates the saved config is now complete
  2. Triggers a full application restart (call `process.exit(0)` — Docker's `restart: unless-stopped` will restart the container with the new config)

```typescript
class WebServer {
    #app: express.Application;
    #queue: MailQueue | null;
    #smtpServer: SMTPServer | null;
    #setupMode: boolean;

    constructor(queue: MailQueue | null, smtpServer: SMTPServer | null) {
        this.#queue = queue;
        this.#smtpServer = smtpServer;
        this.#setupMode = (queue === null || smtpServer === null);
        // ... rest of setup
    }
```

**Route mounting logic:**
```typescript
// Always mount config routes (needed for setup)
configRoutes(this.#app);
accountRoutes(this.#app);

// Setup mode endpoints
this.#app.get('/api/setup-status', (_req, res) => {
    res.json({ setupMode: this.#setupMode });
});

if (this.#setupMode) {
    this.#app.post('/api/setup/complete', (_req, res) => {
        // Re-read config and check if it's now complete
        // If yes, respond with success and schedule restart
        // If no, respond with what's still missing
    });
}

// Only mount health routes when NOT in setup mode (they need queue/smtp refs)

    healthRoutes(this.#app, this.#queue!, this.#smtpServer!);
}
```

**For the `/api/setup/complete` endpoint:**
```typescript
this.#app.post('/api/setup/complete', async (_req, res) => {
    try {
        // Force re-read of config
        const configService = new ConfigService();
        const config = await configService.getConfig(true);

        // Check if send config or accounts exist
        const hasAccounts = config.accounts && Array.isArray(config.accounts) && config.accounts.length > 0;
        const hasSendConfig = config.send?.appReg?.tenant && config.send?.appReg?.id;
        const isReceiveOnly = config.mode === 'receive';

        if (!hasAccounts && !hasSendConfig && !isReceiveOnly) {
            return res.status(400).json({
                error: 'Configuration incomplete',
                missing: 'Add at least one relay account or configure send.appReg with tenant and client ID'
            });
        }

        res.json({ success: true, message: 'Configuration complete. Restarting...' });

        // Give the response time to send, then restart
        setTimeout(() => {
            log.info('Setup complete — restarting with full configuration...');
            process.exit(0); // Docker restart policy will restart the container
        }, 1000);
    } catch (err) {
        res.status(500).json({ error: 'Failed to validate configuration' });
    }
});
```

```javascript
function showSetupWizard() {
    // Hide normal tab bar
    document.querySelector('.tab-bar').style.display = 'none';

    // Hide all normal tab content
    document.querySelectorAll('[id^="tab-"]').forEach(el => el.style.display = 'none');

    // Show the setup wizard content
    const wizard = document.getElementById('setup-wizard');
    if (wizard) wizard.style.display = 'block';

    // Update window title
    document.querySelector('.title-bar-text').textContent = 'SMTP2Graph — Setup Wizard';

    initSetupWizard();
}

function initSetupWizard() {
    // Wizard has 3 steps:
    // Step 1: Welcome + WebUI credentials (change default password)
    // Step 2: Relay account setup (tenant, app ID, cert/secret)
    // Step 3: SMTP server settings (port, TLS, auth)
    // Final: Review & Complete

    let currentStep = 1;
    const totalSteps = 4;

    renderStep(currentStep);

    document.getElementById('wizard-next').addEventListener('click', async () => {
        if (await validateStep(currentStep)) {
            currentStep++;
            if (currentStep > totalSteps) {
                await completeSetup();
            } else {
                renderStep(currentStep);
            }
        }
    });

    document.getElementById('wizard-back').addEventListener('click', () => {
        if (currentStep > 1) {
            currentStep--;
            renderStep(currentStep);
        }
    });
}
```

**Validation per step:**

```javascript
async function validateStep(step) {
    switch (step) {
        case 1: {
            const pass = document.getElementById('setup-webui-pass').value;
            const confirm = document.getElementById('setup-webui-pass-confirm').value;
            if (pass.length < 8) {
                showAlert('Validation Error', 'Password must be at least 8 characters.');
                return false;
            }
            if (pass !== confirm) {
                showAlert('Validation Error', 'Passwords do not match.');
                return false;
            }
            return true;
        }
        case 2: {
            const tenant = document.getElementById('setup-acct-tenant').value;
            const clientId = document.getElementById('setup-acct-clientid').value;
            if (!tenant || !clientId) {
                showAlert('Validation Error', 'Tenant and Client ID are required.');
                return false;
            }
            return true;
        }
        case 3:
            return true; // SMTP settings all have defaults
        case 4:
            return true; // Review step — just confirm
    }
}
```

**Complete setup — save config and trigger restart:**

```javascript
async function completeSetup() {
    // Build the full config object from wizard data
    const authMethod = document.querySelector('input[name="setup-auth-method"]:checked')?.value;

    const account = {
        name: document.getElementById('setup-acct-name')?.value || 'default',
        appReg: {
            tenant: document.getElementById('setup-acct-tenant')?.value,
            id: document.getElementById('setup-acct-clientid')?.value,
        }
    };

    if (authMethod === 'certificate') {
        account.appReg.certificate = {
            thumbprint: document.getElementById('setup-acct-thumbprint')?.value,
            privateKeyPath: document.getElementById('setup-acct-keypath')?.value
        };
    } else {
        account.appReg.secret = document.getElementById('setup-acct-secret')?.value;
    }

    const mailbox = document.getElementById('setup-acct-mailbox')?.value;
    if (mailbox) account.forceMailbox = mailbox;

    const config = {
        mode: 'full',
        accounts: [account],
        receive: {
            port: parseInt(document.getElementById('setup-smtp-port')?.value) || 587,
            listenAddress: document.getElementById('setup-smtp-listen')?.value || '0.0.0.0',
            maxSize: document.getElementById('setup-smtp-maxsize')?.value || '25m'
        },
        webui: {
            enabled: true,
            port: 3000,
            listenAddress: '0.0.0.0',
            username: document.getElementById('setup-webui-user')?.value || 'admin',
            password: document.getElementById('setup-webui-pass')?.value
        }
    };

    // Add SMTP auth if enabled
    if (document.getElementById('setup-smtp-auth')?.checked) {
        config.receive.requireAuth = true;
        config.receive.users = [{
            username: document.getElementById('setup-smtp-user')?.value,
            password: document.getElementById('setup-smtp-pass')?.value
        }];
    }

    try {
        // Save the config
        const saveRes = await apiFetch('/api/config', {
            method: 'PUT',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify(config)
        });

        if (!saveRes.ok) {
            const err = await saveRes.json();
            showAlert('Error', 'Failed to save config: ' + (err.error || 'Unknown error'));
            return;
        }

        // Trigger restart
        const completeRes = await apiFetch('/api/setup/complete', { method: 'POST' });
        const result = await completeRes.json();

        if (completeRes.ok) {
            // Show restart message
            document.getElementById('wizard-content').innerHTML = `
                <fieldset class="group-box">
                    <legend>Setup Complete</legend>
                    <p style="margin: 16px 8px; text-align: center; font-size: 14px;">
                        <b>Configuration saved successfully!</b><br><br>
                        The container is restarting...<br>
                        This page will reload automatically.
                    </p>
                </fieldset>
            `;
            document.getElementById('wizard-next').style.display = 'none';
            document.getElementById('wizard-back').style.display = 'none';

            // Poll until the server comes back
            setTimeout(function pollRestart() {
                fetch('/api/setup-status')
                    .then(r => r.json())
                    .then(data => {
                        if (!data.setupMode) {
                            window.location.reload();
                        } else {
                            setTimeout(pollRestart, 2000);
                        }
                    })
                    .catch(() => setTimeout(pollRestart, 2000));
            }, 3000);
        } else {
            showAlert('Error', result.error || 'Setup completion failed');
        }
    } catch (e) {
        showAlert('Error', 'Network error: ' + e.message);
    }
}
```

```javascript
function renderStep(step) {
    // ... existing switch/case ...

    // Post-render hooks
    if (step === 2) {
        setTimeout(() => {
            const certRadio = document.getElementById('setup-auth-cert');
```
